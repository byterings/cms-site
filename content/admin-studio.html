Admin Studio guide

The Admin Studio is the web interface for managing your workspace. Everything it does goes through the same API your own applications use.

Signing in

  • First run: open /setup to create the organization and the first owner (see Quickstart).
  • Afterwards: sign in at /login with your email and password. Sessions last 7 days by default.
  • Several workspaces: in multi-tenant mode, a workspace switcher appears at the top of the sidebar.
  • Password: change it under Settings → Account. All your other sessions are signed out.

The sidebar only shows what your role allows. Viewers, for example, don't see Schema, Members or API keys.

Dashboard

The dashboard lists every content type with its number of records. Click a card to open the records.

Schema builder

Schema lists your entities. Click New entity, enter a name (singular, for example Product), and the API key is suggested automatically. Open an entity to:

  • Add fields: choose a label (the key is generated), a type and its settings, then the rules:
    • Required: a value must be present.
    • Unique: no two records may share a value (text comparisons ignore case).
    • Visible in public API: include the field in anonymous responses.
    • Readable by / Writable by: the minimum role that can see or edit the field.
    • Default value: used when a new record doesn't set the field.
  • Edit fields (pencil icon): the key and type are fixed, everything else can change.
  • Reorder fields with the arrows. The order is used in forms.
  • Delete fields: removes the field and its values from every record.
  • Settings: name, plural name, description, title field, status (Archived makes records read-only), and public API access (see Public API).
  • Delete the entity: only possible when it has no live records and no other entity links to it.
Schema changes are safe to try

Invalid settings are rejected with a message next to the field, and every change is stored in the entity's version history.

Managing content

Each active entity appears under Content in the sidebar.

  • List: search text fields, sort by clicking column headers, page through results. Related records show their titles.
  • Create and edit: forms are generated from the fields. Values are checked as you save, and the server checks them again. Fields you can't edit are shown read-only.
  • Slugs: slug fields fill in from the title automatically on new records until you edit them yourself.
  • Relations: type to search the target entity and pick one or more records.
  • Media: click Choose file to pick from the library or upload a new file.
  • Conflicts: if someone else saved the record while you were editing, saving shows a warning instead of overwriting their changes. Reload to get the latest version.
  • Trash: deleted records go to the trash. Admins tick Show deleted to restore them or delete them permanently.

Media library

Media shows every uploaded file. Click Upload or drag files onto the page. Click a file to set its alternative text (important for accessibility and SEO), rename it, open it or delete it.

Allowed types: PNG, JPEG, GIF, WebP, MP4, WebM, MP3, WAV, OGG, PDF, plain text and CSV, up to 10 MB by default. SVG is not accepted, because SVG files can contain scripts.

Members

Settings → Members (admins and owners):

  • Add member: enter the email and role. For someone without an account yet, also enter their name and an initial password (12+ characters) and share it with them securely.
  • Change role with the dropdown, or remove a member. Access ends immediately.

API keys

Build → API keys: create keys for websites, apps and scripts.

  1. Click New API key, name it (for example Website production) and choose scopes.
  2. Optionally set an expiry date.
  3. Copy the key from the confirmation dialog. It is shown only once.
ScopeAllows
records:readList and read records
records:writeCreate, update and delete records
metadata:readRead entities and fields
metadata:writeChange entities and fields, schema sync from the CLI
media:read / media:writeRead or upload and manage media

Give each key only the scopes it needs. Revoking a key stops it working immediately.

Audit log

Settings → Audit log lists sensitive actions with time, actor, target and changed field names. Filter by action, for example record.updated.

Templates & plugins

Build → Templates & plugins:

  • Install a template, optionally with sample content.
  • Review upgrade when a newer template version is available. You see exactly what will change before anything happens.
  • Enable or disable plugins for this workspace.

Workspace settings

Owners can rename the workspace under Settings → Account. The workspace slug is used in public API URLs and cannot be changed there.
