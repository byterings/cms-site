Installation

Create a new ByteContent project with your favourite package manager, connect it to PostgreSQL and open the Admin Studio.

The installer is coming soon

The create-bytecontent installer and the bytecontent command described on this page are in development and not yet published to npm. Today, install ByteContent from source with the Quickstart; it takes about ten minutes.

Requirements

ToolVersionNotes
Node.js22 or newer (24 LTS recommended)nodejs.org
Package managernpm, pnpm, yarn or bunUse whichever you prefer
PostgreSQL16 or newerLocal, Docker or a managed service (Neon, Supabase, RDS, …)

ByteContent does not install PostgreSQL for you. Bring an existing server, or start one with Docker:

```bash docker run -d --name bytecontent-db -p 5432:5432 \ -e POSTGRES_PASSWORD=postgres postgres:17 ```

Create a project

```bash npx create-bytecontent@latest my-cms ```
```bash pnpm create bytecontent my-cms ```
```bash yarn create bytecontent my-cms ```
```bash bun create bytecontent my-cms ```

Answer the setup questions

The installer asks for your database connection, like other popular CMSs do, and checks it before it continues:

```text ? Project name my-cms ? Tenancy mode single (one organisation) ? Database host localhost ? Database port 5432 ? Database name bytecontent ? Database user bytecontent ? Database password ******** ? Use SSL? No ✔ Connected to PostgreSQL 17.2 ✔ Wrote .env ✔ Applied database migrations ```

If the database cannot be reached, the installer does not stop. It writes the project and the .env file, shows a warning, and tells you how to fix it. Run bytecontent doctor any time to check the connection again.

All settings live in one .env file in the project root. See Configuration for every option.

Start ByteContent

```bash cd my-cms npm run dev ```
```bash cd my-cms pnpm dev ```
```bash cd my-cms yarn dev ```
```bash cd my-cms bun run dev ```

Open http://localhost:3000/setup to create the first administrator, then sign in to the Admin Studio.

The bytecontent command

CommandWhat it does
bytecontent devStart the API and Admin Studio in development mode
bytecontent build / startBuild and run for production
bytecontent setupCreate the first administrator from the terminal
bytecontent migrateApply pending database migrations
bytecontent doctorCheck Node.js, the database connection, migrations and settings
bytecontent backup / restoreBack up and restore the database and media

The schema commands (export, schema:diff, schema:push, types) are described in the CLI reference.
