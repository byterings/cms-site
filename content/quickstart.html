Quickstart

Run the platform locally, create your administrator account and publish your first record in about ten minutes.

Prerequisites

ToolVersionNotes
Node.js22 or newer (24 LTS recommended)nodejs.org
pnpm10npm install -g pnpm@10
PostgreSQL16 or newerDocker, a native install, or the bundled Windows script
Gitany recent

1. Get the code

```bash git clone https://github.com/byterings/byteringscms.git cd byteringscms pnpm install ```

2. Start PostgreSQL

Choose one option:

With Docker

```bash docker compose up -d ```

This starts PostgreSQL 17 and creates the application role and databases automatically.

Native PostgreSQL

Install PostgreSQL, then create the application role and databases with the superuser connection:

```bash ADMIN_DATABASE_URL=postgresql://postgres:@localhost:5432/postgres pnpm db:setup-local ```

Windows without administrator rights

```powershell powershell -File scripts/local-postgres.ps1 install # once: downloads PostgreSQL into your user folder powershell -File scripts/local-postgres.ps1 start # after every restart pnpm db:setup-local ```
The application role is not a superuser

The scripts create a role named byterings without superuser or BYPASSRLS rights. This matters: PostgreSQL row-level security only protects tenant data for roles like this.

3. Configure the environment

```bash cp apps/api/.env.example apps/api/.env cp apps/admin/.env.example apps/admin/.env.local ```

The defaults work for local development. See Configuration for every option.

4. Build, migrate and run

```bash pnpm build # compiles all packages pnpm db:deploy # applies database migrations pnpm dev # API on http://localhost:4000, Admin Studio on http://localhost:3000 ```

5. Create your administrator

There is no default username or password. Every installation creates its own administrator on first run.

  1. Open http://localhost:3000/setup.
  2. Enter your organization name and slug (for example acme), your name, your email (your login ID) and a password with at least 12 characters.
  3. Click Create installation. You are signed in as the owner and platform administrator.

Setup runs only once. Afterwards, sign in at http://localhost:3000/login.

6. Build your first content type

  1. Open Schema and click New entity. Name it Product. The API key product is filled in for you.
  2. Click Add field and create:
    • Name: Text, required
    • Price: Decimal, required, minimum 0
    • Is active: Boolean, default value on
  3. In the sidebar under Content, open Products and click New product. Fill in the form and click Create.

7. Read it through the API

Create an API key in API keys with the records:read scope, then:

```bash curl -H "Authorization: Bearer bcms_xxxxxxxx_your-secret" \ "http://localhost:4000/api/v1/entities/product/records?sort=-price" ``` ```json { "data": [ { "id": "7b0a2a4e-7d4b-4b8c-9a46-0f1f7c3e9a11", "entity": "product", "data": { "name": "Desk lamp", "price": "19.90", "isActive": true }, "version": 1, "createdAt": "2026-11-14T10:00:00.000Z", "updatedAt": "2026-11-14T10:00:00.000Z" } ], "meta": { "page": 1, "pageSize": 20, "total": 1, "totalPages": 1 } } ```

Interactive API documentation is available at http://localhost:4000/api/v1/docs.
