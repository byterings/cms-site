Build content apps without hardcoding them

ByteContent is an open-source, multi-tenant, metadata-driven platform. Define your content types in the Admin Studio, and get validated storage, permissions, a REST API, a public content API and a typed SDK instantly. Self-host it, or run it as SaaS from the same codebase.

How it works

Everything starts with metadata. An entity (for example Product or Article) is a set of fields. The platform reads these definitions at runtime and uses them everywhere:

  • Storage: records are stored in PostgreSQL and validated against their field definitions.
  • API: every entity is available at /api/v1/entities/<key>/records.
  • Admin Studio: forms, tables and pickers are generated from the same definitions.
  • Security: roles, field-level read/write rules and tenant isolation apply to every request.

The browser and the API share one contract, so what you build in the UI works the same way through the API, and the reverse.

```text Websites / apps / Admin Studio / CLI │ REST API v1 ── OpenAPI 3.1 │ Tenant context · authentication · roles │ Metadata engine · validation · relations │ PostgreSQL (JSONB + row-level security) ```
