Field types

Every field has one of eleven types. The type decides the input in the Admin Studio, how values are validated and stored, how they look in the API, and which filters work on them.

Empty values are returned as null. Sending null (or an empty string or array) clears an optional field. Required fields reject empty values.

Text

A single line of text. Leading and trailing spaces are trimmed.

SettingDefaultDescription
maxLength2551 to 10,000 characters
minLengthnoneMinimum length
formatplainplain, email, url (http/https only), or slug (lower-case words separated by hyphens)

Long text

Multi-line text such as article bodies. Settings: maxLength (default 100,000; up to 1,000,000) and markdown (a hint for editors and frontends that the content is Markdown).

Integer and decimal

  • Integer: whole numbers within JavaScript's safe range, with optional min and max.
  • Decimal: exact decimals, returned as strings so no precision is lost. Settings: min, max and scale (decimal places, default 2). Input 19.9 is stored as "19.90". More decimal places than the scale allows is an error.

Boolean

Only true or false. Strings such as "true" are rejected in the request body (filters accept true/false in the query string).

Date and date-time

  • Date: a calendar date YYYY-MM-DD, checked for validity (no 30 February). Optional min and max.
  • Date-time: any ISO 8601 timestamp with a timezone. It is stored and returned in UTC, for example "2026-11-14T08:00:00.000Z".

Select and multi-select

Choose from a fixed list of options, each with a value (stored, used in the API: letters, digits, _ . -) and a label (shown in the UI).

```json { "options": [ { "value": "draft", "label": "Draft" }, { "value": "published", "label": "Published" } ] } ```

Multi-select also supports minItems and maxItems, and returns values in an array without duplicates.

Relation

Links to records of another entity in the same workspace.

SettingDescription
targetEntityIdThe entity to link to (in schema files: targetEntity with the entity key)
cardinalityone (default) or many
maxItemsFor many: up to 100 (default)

Targets must exist, must belong to the target entity, and must not be in the trash. Use ?expand=field to get the linked records inline. If a linked record is deleted permanently, the reference is removed automatically. The target and cardinality can only change while no record uses the field.

Media

References files in the media library. Settings: multiple (allow several files), maxItems, and accept, a list of allowed kinds: image, video, audio, document.
